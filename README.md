# WhatBot

Production multi-vendor Ghana e-commerce platform built with Next.js 14, TypeScript, Tailwind CSS, Prisma and PostgreSQL.

Core modules include customer storefront, seller dashboard, admin controls, authentication, Paystack initialization/webhooks, WhatsApp Cloud API routing, product search, seller subscriptions, Jumia/Amazon import services and Ghana-specific legal pages.

Configure server environment variables before enabling external providers.
